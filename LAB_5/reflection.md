
# Lab 5 – Reflection

### 1. What is static code analysis?

Static code analysis examines source code without executing the program to identify potential bugs, security vulnerabilities and coding standard violations.

### 2. What is the purpose of Pylint, Bandit and Flake8?

Pylint checks code quality and programming practices. Bandit identifies common security vulnerabilities in Python code. Flake8 checks code formatting and compliance with PEP 8 guidelines.

### 3. What did you learn from this lab?

I learned how to use static analysis tools to identify and fix issues in Python programs. I also understood the importance of secure coding practices, proper naming conventions and readable code.

### 4. Why is static code analysis important?

It helps developers identify problems early, improve maintainability, reduce security risks and maintain consistent coding standards.
